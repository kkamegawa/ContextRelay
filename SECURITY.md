# Security Policy

## Reporting a vulnerability

Please do not open public GitHub issues for suspected security vulnerabilities.

Instead, report them privately to the maintainers with:

- a clear description of the issue
- affected versions or commit ranges
- reproduction steps or a proof of concept
- any suggested remediation, if available

If GitHub Security Advisories is enabled for this repository, please prefer that channel. Otherwise, contact the maintainer directly and include `ContextRelay security report` in the subject line.

## What to expect

We will review reports as quickly as possible, validate impact, and coordinate a fix before public disclosure when appropriate.
