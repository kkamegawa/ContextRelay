ContextRelay Settings

Configure settings via File > Preferences > Settings (search "contextRelay").

  • contextRelay.maxResults — Results per source (default: 10)
  • contextRelay.cache.ttlSeconds — Cache TTL in seconds (default: 300)
  • contextRelay.enableChatPreview — Enable Chat tab (default: true)
  • contextRelay.adapters.mail — Enable Mail adapter
  • contextRelay.adapters.teams — Enable Teams adapter
  • contextRelay.adapters.sharepoint — Enable SharePoint adapter
  • contextRelay.adapters.onedrive — Enable OneDrive adapter
